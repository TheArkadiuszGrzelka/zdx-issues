# zdx issues

Public issue tracker for [zdx](https://embeddeddx.com), the Zephyr and nRF Connect SDK
developer CLI and its Claude Code plugin. The zdx source repository is private; report
bugs and request features here.

## Before you file

- Search the existing issues first.
- Run `zdx --version` and include the output.
- Remove anything secret from logs: licence tokens, signing keys, Wi-Fi credentials,
  private paths you do not want public.

## What to include

- What you ran (the exact command).
- What happened, with the relevant part of the output.
- What you expected instead.
- Host OS, zdx version, and the Zephyr or NCS version of the project.
